# 20 Humanized Cold Outreach Drafts — OpenCorp Day 1

**Bazzly-aligned, but pivoted to public reply format because no Premium.**

Without X Premium, DMs go to Message Requests (mostly ignored, ~1-3% reply).
With public replies on the recipient's most recent tweet:
- visible to all (free distribution, not just the recipient)
- no follower requirement
- reply thread context (their original post shows)
- profile bio carries the opencorp link

Humanization rules applied (per `humanizer` skill):
- Lowercase throughout (matches Filip's X voice)
- No em dashes (replaced with periods, commas, colons, parens)
- No "stands as", "serves as", "boasts a"
- No "additionally", "crucial", "delve"
- Specific names + product names + revenue numbers
- No marketing fluff, no emojis, no boldface

**Reply format constraint:** ≤280 chars per reply. Reply thread on their tweet, opencorp in profile bio carries the link.

## Send path (no Premium, free)

1. **Targets 1-4** — check footer of their site for emails. Email is best.
2. **Targets 5-18** — public reply on their most recent tweet. Copy the reply above. Don't DM.
3. **Targets 19-20** — blocked. Set up `opencorp` brand Reddit account, build 14 days karma, then reply.
4. **Reply context** — when posting public reply, the reply thread shows their original tweet. Open profile bio of opencorp must already have `opencorp.live` so visitors find the site.

## Setup before sending

1. Update `opencorpai` profile bio to lead with `opencorp.live — find the reddit + HN threads where your users are already talking. free.`
2. Pin a tweet on `opencorpai` that links to `/tools/reddit-thread-finder` so anyone clicking through sees the product immediately.
3. Then send the public replies. Send 3-5/day to avoid looking spammy.
